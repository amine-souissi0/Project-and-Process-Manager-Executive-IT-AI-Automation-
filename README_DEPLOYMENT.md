# 🚀 Quick Deployment for Recruiter

## Deploy in 5 Minutes (Render.com)

1. **Go to:** https://render.com
2. **Sign up/Login** (free account)
3. **Click:** "New +" → "Web Service"
4. **Connect GitHub:** Select your repository
5. **Configure:**
   - Name: `ulink-assist-demo`
   - Build: `pip install -r requirements.txt`
   - Start: `python app.py`
6. **Deploy** → Get your URL!
7. **Share URL with recruiter**

**That's it!** The app will be live at: `https://ulink-assist-demo.onrender.com`

---

## Alternative: Railway.app

1. Go to: https://railway.app
2. New Project → Deploy from GitHub
3. Select repository
4. Auto-deploys!
5. Get URL and share
